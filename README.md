# Приложение продажи автомобилей

Десктопное приложение на Python с использованием Tkinter и SQLite для просмотра, добавления и удаления автомобилей.

## Доступные версии приложения

В этом проекте доступны две версии приложения:

1. **Десктопная версия** - использует Tkinter и SQLite3 (запускается через `main.py`)
2. **Веб-версия** - использует Flask и PostgreSQL (запускается через `web_app.py`, требует дополнительные библиотеки)

## Описание

Приложение позволяет:
- Просматривать список доступных автомобилей
- Просматривать детальную информацию об автомобиле
- Входить в панель администратора
- Добавлять новые автомобили (с изображением)
- Удалять существующие автомобили

## Требования

- Python 3.8 или выше
- Pillow (PIL) для работы с изображениями
- SQLite3 (включен в стандартную библиотеку Python)
- Tkinter (обычно включен в стандартную установку Python)

## Установка

1. Клонируйте или скачайте репозиторий
2. Установите необходимые зависимости:

```bash
pip install pillow
```

## Запуск приложения

### Запуск десктопной версии (Tkinter)

```bash
python main.py
```

### Запуск веб-версии (Flask)

Для запуска веб-версии вам потребуется установить дополнительные зависимости:

```bash
pip install flask flask-sqlalchemy psycopg2-binary pillow
```

И настроить подключение к базе данных PostgreSQL через переменную окружения:

```bash
export DATABASE_URL=postgresql://username:password@host:port/database
```

Затем запустите веб-сервер:

```bash
python web_app.py
```

## Структура проекта

### Десктопная версия (Tkinter)

- `main.py` - Главный файл для запуска десктопного приложения
- `ui.py` - Графический интерфейс на Tkinter
- `database.py` - Работа с базой данных SQLite
- `auth.py` - Аутентификация администратора для десктопной версии
- `utils.py` - Вспомогательные функции для работы с изображениями и UI

### Веб-версия (Flask)

- `web_app.py` - Главный файл для запуска веб-приложения
- `models.py` - Модели данных SQLAlchemy для веб-версии
- `templates/` - HTML шаблоны для веб-интерфейса
- `static/` - Статические файлы (CSS, JavaScript, изображения)

## Функциональность

### Роли пользователей

1. **Покупатель**
   - Просмотр списка автомобилей с карточками и изображениями
   - Просмотр детальной информации при клике на карточку
   - Удобный интерфейс с выделением при наведении курсора

2. **Администратор**
   - Управление каталогом автомобилей через табличное представление
   - Добавление новых автомобилей с изображениями
   - Удаление существующих автомобилей через интерфейс
   - Защищенный интерфейс с авторизацией

### Интерфейс приложения

- Современный дизайн с акцентными цветами
- Стилизованные кнопки разных типов (основные, удаления, успеха)
- Карточки автомобилей с эффектами при наведении
- Подробное отображение характеристик в текстовом формате
- Поддержка загрузки и отображения изображений

### База данных

Приложение использует локальную базу данных SQLite (`car_sales.db`), которая создается автоматически при первом запуске. Схема базы данных включает информацию об автомобилях (название, цена, характеристики, изображение).
